# Poster research companion

Static HTML website for GitHub Pages. Keep index.html, styles.css, script.js, videos.json, images and documents together at the repository root.

## Video links
All four Google Drive videos are embedded directly in index.html. videos.json records the original links; editing that file alone does not update the page. Edit the corresponding iframe and fallback link in index.html to change a clip. Use Anyone with the link / Viewer, then test while signed out. Large video originals are intentionally excluded.

## Before publication
- Confirm the attacker (0–5 / 6+) and defender (0–7 / 8+) coding thresholds against the analysis. The webpage draft uses the agreed thresholds; the original downloadable definition files retain their supplied wording.
- Confirm freeze-frame match/event identifiers if they are to be labelled as specific match examples.
- Review the supplied definition of near-post shooting area (“left side”) and angle/length category boundaries against the coding method.
- Test all four videos while signed out and confirm Portugal–Switzerland coaching focus.
- Compare model numbering between poster and supplementary document; the site uses outcome names to avoid ambiguity.
