# Poster research companion

Static HTML website for GitHub Pages. Keep index.html, styles.css, script.js, videos.json, images and documents together at the repository root.

## Video links
All four Google Drive videos are embedded directly in index.html. videos.json records the original links; editing that file alone does not update the page. Edit the corresponding iframe and fallback link in index.html to change a clip. Use Anyone with the link / Viewer, then test while signed out. Large video originals are intentionally excluded.
